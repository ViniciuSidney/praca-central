# Testes Manuais — Praça Central v0.1

## Preparação

1. Abrir o projeto com Live Server.
2. Abrir o Console do navegador.
3. Confirmar ausência de erros JavaScript.
4. Executar os testes em tema escuro e claro.

## Checklist funcional

- [ ] A página carrega corretamente.
- [ ] Os dois cards aparecem.
- [ ] O contador mostra 2 destinos.
- [ ] A busca filtra por nome.
- [ ] A busca filtra por descrição.
- [ ] A busca ignora acentos e diferenças entre maiúsculas e minúsculas.
- [ ] O filtro Foco mostra Time Task.
- [ ] O filtro Organização mostra Note and Finish.
- [ ] O filtro Todas restaura os cards.
- [ ] O estado vazio aparece sem resultados.
- [ ] O botão de limpar restaura busca e filtros.
- [ ] O modal de detalhes mostra os dados corretos.
- [ ] Os modais fecham por botão, clique externo e Esc.
- [ ] O tema alterna corretamente.
- [ ] O tema persiste após recarregar.
- [ ] Links vazios ficam desabilitados.
- [ ] Links preenchidos abrem em nova aba.
