# Visão do Projeto

## Nome do projeto

Praça Central

## Ideia principal

A Praça Central é uma aplicação web instalável que reúne e apresenta outras aplicações pessoais publicadas de forma independente. Ela funciona como porta de entrada para o ecossistema de ferramentas do criador.

## Problema que resolve

Com o crescimento da quantidade de aplicações, os endereços ficam dispersos e o usuário precisa lembrar ou procurar cada link separadamente. A Central concentra esses caminhos em uma interface única, organizada e acessível também como aplicativo instalado.

## Objetivo principal

Permitir que o usuário identifique rapidamente a ferramenta adequada para sua necessidade e acesse a aplicação escolhida com poucos cliques.

## Objetivos da experiência PWA

- permitir instalação no computador ou celular;
- abrir a Central em uma janela própria;
- manter a interface principal disponível offline;
- comunicar perda de conexão de forma clara;
- avisar quando uma nova versão estiver pronta;
- preservar a independência das aplicações externas.

## Público-alvo

Inicialmente, o próprio criador das aplicações. Futuramente, qualquer pessoa que tenha acesso aos projetos publicados e queira conhecer ou utilizar as ferramentas.

## Diferenciais

- metáfora visual de uma praça com destinos;
- aplicações independentes, sem integração forçada;
- instalação progressiva sem dependências externas;
- funcionamento offline da própria Central;
- arquitetura preparada para crescer;
- base reutilizada do Modelo de Projeto pessoal.

## Versão atual

v0.3 — FlashCore na Praça

## Aplicações disponíveis

- Time Task;
- Note and Finish;
- FlashCore.

## Observação central

A instalação da Praça Central não instala automaticamente as aplicações ligadas a ela. Cada destino mantém seu próprio repositório, endereço, ciclo de desenvolvimento e estratégia offline.
