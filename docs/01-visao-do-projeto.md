# Visão do Projeto

## Nome do projeto

Praça Central

## Ideia principal

A Praça Central é uma aplicação web que reúne e apresenta outras aplicações pessoais publicadas de forma independente. Ela funciona como uma porta de entrada para o ecossistema de ferramentas do criador.

## Problema que resolve

Com o crescimento da quantidade de aplicações, os endereços ficam dispersos e o usuário precisa lembrar ou procurar cada link separadamente. A Central concentra esses caminhos em uma interface única, organizada e fácil de consultar.

## Objetivo principal

Permitir que o usuário identifique rapidamente a ferramenta adequada para sua necessidade e acesse a aplicação escolhida com poucos cliques.

## Público-alvo

Inicialmente, o próprio criador das aplicações. Futuramente, qualquer pessoa que tenha acesso aos projetos publicados e queira conhecer ou utilizar as ferramentas.

## Diferencial da aplicação

- usa a metáfora visual de uma praça com destinos;
- mantém cada aplicação independente;
- cresce sem exigir mudanças estruturais grandes;
- funciona sem login, backend ou banco de dados;
- reutiliza o Modelo de Projeto pessoal.

## Versão atual

v0.1 — Fundação da Praça

## Aplicações iniciais

- Time Task;
- Note and Finish.

## Observações iniciais

A Central não deve duplicar funcionalidades das aplicações. Seu papel é apresentar, organizar, filtrar e direcionar o usuário para os projetos independentes.
